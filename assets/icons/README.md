# Logos

The logos in the profile images, shown in their own colours on white plates (the SSB
identity's rule for outside logos; white is its colour for partner plates):

- `*-original.svg`, `docker-plain.svg`: [Devicon](https://devicon.dev) 2.16.0, MIT licence.
  `linkedin-original.svg` is recoloured to LinkedIn's current blue, #0A66C2.
- `arm.svg`: [Simple Icons](https://simpleicons.org) 13.21.0, CC0 1.0, drawn in Arm's blue #0091BD.
- x86 has no logo, so it is set in Sofia Sans.

The logos are trademarks of their owners and are used here only to name the tools and to
link the LinkedIn profile.
