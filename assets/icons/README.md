# Logos

The technology and LinkedIn logos used in the profile images, from
[Simple Icons](https://simpleicons.org) 13.21.0 (CC0 1.0). The logos themselves are
trademarks of their owners and are used here only to name the tools and link the profile.
They are drawn in one colour (ink on Paper, Paper on Pine), as the SSB identity allows
no other colours. x86 has no logo, so it is set in Sofia Sans.
